## About

This repository contains source code reconstructed from the compiled files of Project Viewpoint.

The purpose of this repository is to document the code structure of the project and make its implementation easier to inspect and understand.

Because the files were generated through decompilation, they may differ significantly from the original source code used by the developers.

This repository is maintained independently and is not affiliated with or endorsed by the original Project Viewpoint development team.
